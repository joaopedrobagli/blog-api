Como testar

1

Crie uma conta

Na documentação, use POST /api/auth/register com seu usuário e senha.

"username": "seu_nome"
"email": "email@email.com"
"password": "sua_senha"
2

Copie o token

A resposta retorna um token JWT. Copie o valor do campo "token".

3

Autorize e explore

Clique em Authorize no topo do Swagger, cole o token e teste todos os endpoints livremente.
